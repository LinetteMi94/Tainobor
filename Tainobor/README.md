# Тайнобор 🪄

Тайнобор — консольный симулятор жизни студента магической академии.

Игрок поступает в академию и проходит учебный путь: посещает занятия, изучает магические дисциплины, готовится к экзаменам, развивает способности, общается с преподавателями и однокурсниками и сталкивается с неожиданными событиями.

## Возможности

Проект находится в разработке. Планируется реализовать:
создание персонажа;
учебное расписание;
магические дисциплины;
обучение и развитие навыков;
экзамены и оценки;
отношения с преподавателями и студентами;
случайные события;
открытие и развитие магических способностей;
сохранение игрового прогресса.

## Технологии
C#
.NET 9.0
Console Application

## Цель проекта

Проект создаётся как самостоятельная практика программирования на C# и применения принципов объектно-ориентированного программирования.

Архитектура и игровые механики разрабатываются постепенно по мере развития проекта.
